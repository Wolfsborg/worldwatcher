Privacy

This is a static public map. There are no user accounts and we do not ask you to create one.

What this site stores

We do not run our own analytics cookies or advertising trackers. The incident database is a public JSON file.

What other services may see

  • Map tiles and place names are loaded from Esri and Leaflet CDNs. Those providers may see your IP address and standard browser request data.
  • Fonts are loaded from Google Fonts.
  • If you send a correction, the report opens a GitHub issue on the public worldwatcher repository. GitHub’s privacy terms then apply to whatever you write there.

Contact

For a privacy question about this site, use Report a correction on any incident and say it is about privacy, or open an issue on the worldwatcher repository.
